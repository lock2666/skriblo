# 🖌️ سكربلو (Skriblo)

لعبة **جماعية أونلاين** للرسم والتخمين مع دردشة فورية، بواجهة عربية كاملة (RTL) — شبيهة بـ Skribbl.io.

**الاسم:** Skriblo / سكربلو

---

## 🚀 التشغيل محلياً

```bash
npm install
npm start
# ثم افتح http://localhost:3000
```

أو على ويندوز: اضغط مرتين على **`ابدأ.bat`**.

---

## 🌐 النشر على الإنترنت

اللعبة consist من جزأين:

| الجزء | التقنية | أين يُنشر |
|---|---|---|
| الواجهة (public/) | HTML/CSS/JS | **GitHub Pages** |
| السيرفر (server.js + socket.io) | Node.js | **Render.com** (مجاني) |

### 1) انشر السيرفر على Render (مجاني)
1. أنشئ حساباً على [render.com](https://render.com) واربطه بـ GitHub.
2. **New + → Blueprint** واختر هذا المستودع (يقرأ `render.yaml` تلقائياً).
3. انتظر اكتمال النشر وانسخ رابط السيرفر (مثل `https://skriblo.onrender.com`).

> الخطة المجانية «تنام» بعد ~15 دقيقة من عدم الاستخدام، فأول اتصال يأخذ ~30 ثانية للاستيقاظ.

### 2) انشر الواجهة على GitHub Pages
1. في GitHub: **Settings → Pages → Source: GitHub Actions**.
2. عدّل `public/config.js` وضع رابط سيرفر Render:
   ```js
   window.SKRIBLO_SERVER = 'https://skriblo.onrender.com';
   ```
3. ادفع التغيير (push) — سيُنشر تلقائياً على `https://<user>.github.io/<repo>/`.

## 🎮 طريقة اللعب

1. أنشئ غرفة وشارك الرابط (`?room=ABCD`) مع أصدقائك (2–12 لاعباً).
2. في كل دور لاعب يرسم كلمة، والبقية يخمّنون في الدردشة.
3. **كل من يجيب الكلمة يأخذ نقاط** (أسرع = نقاط أعلى، +10 مكافأة للأول)، والرسام يأخذ 25 نقطة عن كل تخمين صحيح.
4. بعد الجولات يفوز صاحب أعلى نقاط 🏆.

## ⚙️ إعدادات الغرفة (للمضيف)

| الإعداد | الخيارات |
|---|---|
| عدد الجولات | 1 – 10 |
| مدة الرسم | 30 – 240 ثانية |
| اللغة | العربية / English |
| نوع الكلمات العربية | **فصحى** · **عامية** (افتراضي: عربية، موتوسيكل، تاكسي…) · **فصحى + عامية** |
| الصعوبة | سهل · متوسط · صعب · متنوع |
| عدد الهنتات | بدون هنتات حتى 8 (عدد الحروف المكشوفة تدريجياً) |
| كلمات مخصصة | كلماتك مفصولة بفاصلة + خيار «الرسم من المخصصة فقط» |

## ✨ المميزات

- 🎨 لوحة رسم كاملة: فرشاة و14 لوناً وأحجام، ممحاة، تعبئة لونية (Flood fill)، تراجع (Ctrl+Z)، مسح الكل.
- 💬 دردشة جماعية فورية تُستخدم كصندوق تخمين + رسائل «اقتربت كثيراً!».
- 🈯 دعم عربي كامل: RTL + قواميس فصحى/عامية + مطابقة ذكية (تجاهل التشكيل واختصارات الحروف).
- ⏱️ مؤقت وكشف تدريجي للحروف حسب عدد الهنتات.
- 🏆 نقاط + منصة تتويج + إعادة اللعب.
- 👥 حتى 12 لاعباً، إعادة اتصال تلقائية، طرد اللاعبين من المضيف، واجهة تعمل على الجوال.

## 🗂️ بنية المشروع

```

│   ├── style.css
│   ├── app.js
│   └── config.js      # رابط السيرفر الخارجي (عند النشر)
└── .github/workflows/pages.yml
```
